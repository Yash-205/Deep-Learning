01
the big picture

What is regularization?

✓ complete

Regularization is a group of techniques used to reduce overfitting and help a model work better on unseen data. Different regularization methods control overfitting in different ways.

L2

Adds a penalty based on squared weights. It discourages very large weight values.

L1

Adds a penalty based on absolute weight values. It can make some weights exactly zero.

Dropout

Randomly switches off some neurons during training so the network does not depend too much on particular neurons.

Early stopping

Stops training when validation performance starts getting worse.

Batch normalization

Normalizes intermediate activations during training. Its mini-batch behavior can also give some regularizing effect.

Important: L1 and L2 directly penalize weights. Dropout, early stopping and batch normalization control overfitting in other ways.

03
l2 regularization

Square the weights

✓ complete

L2 regularization adds the square of the weights to the normal prediction loss. This gives unnecessarily large weights an extra cost during training.

for one weightLtotal = Ldata + λW²

Ldata = normal prediction loss · W² = weight-dependent penalty · λ = how strongly we apply the penalty.

worked numericalOne weight

Ldata = 4
W = 3
λ = 0.1

1W² = 3² = 9
2λW² = 0.1 × 9 = 0.9
3Ltotal = 4 + 0.9 = 4.9
We did not add a random 0.9. The value 0.9 appeared because W = 3.

Student numerical 1

Ldata = 6 · W = 4 · λ = 0.05

Student numerical 2

Ldata = 3.2 · W = -5 · λ = 0.08

l2 in a network

Now add many weights

✓ complete

A neural network has many weights, so L2 adds the squares of all of them.

many weightsLtotal = Ldata + λ(W₁² + W₂² + W₃² + ...)
worked example
W₁ = 2W₂ = -3W₃ = 1λ = 0.1Ldata = 5
2² + (-3)² + 1² = 14penalty = 0.1 × 14 = 1.4Ltotal = 5 + 1.4 = 6.4

Negative weights are also penalized because squaring removes the sign.

Student numerical · multiple weights

W₁ = 1 · W₂ = -2 · W₃ = 3 · Ldata = 2.5 · λ = 0.2

one idea to keepEach weight contributes its own square.

A single very large weight contributes much more to the L2 penalty than several small weights.

05
how l2 changes gradient descent

What changed in the GD formula?

✓ complete

You already know ordinary gradient descent: it changes W only according to the gradient coming from prediction loss. With L2 regularization, we do not replace gradient descent. We simply add one extra gradient term, 2λW, that discourages unnecessarily large weights.

before regularization

Ordinary gradient descent

gtotal = gdata
gdata = ∂Ldata/∂W
Wnew = W − αgdata
gdata

is the gradient coming from prediction loss. It tells the model how to change W to fit the training data better.

Gradient used by GD: only gdata.
after adding l2

Gradient descent + L2

gtotal = gdata + gpenalty
gdata = ∂Ldata/∂W
gpenalty = ∂(λW²)/∂W = 2λW
Wnew = W − α(gdata + gpenalty)
gdata

still tells the model how to fit the data.

gpenalty

comes from the L2 penalty. For L2, gpenalty = 2λW, so it pushes unnecessarily large |W| toward zero.

Gradient used by GD: gdata + gpenalty.
The change is simple:   ordinary GD uses gdata   →   L2 uses gdata + gpenalty, where gpenalty = 2λW.
the missing link: gradient descent reacts to the gradient Ltotal = Ldata + λW²

When we add λW², the loss value at the current W becomes larger. But the optimizer does not reduce W just because the loss number became larger. The important point is that λW² depends on W, so it changes the gradient used in the GD update.

increase loss by a fixed number

Adding +10 does not shrink W

Lnew = Ldata + 10
gradient

gnew = gdata + 0 = gdata

why?

The number 10 does not depend on W, so its gradient with respect to W is zero.

Result: the loss number is larger, but the GD update for W is exactly the same.
increase loss with a weight-dependent term

Adding λW² does shrink |W|

Lnew = Ldata + λW²
gradient

gnew = gdata + 2λW

why?

λW² changes when W changes, so it contributes the new gradient term 2λW.

Result: the new term changes the GD update and pushes the magnitude |W| toward zero.
Cause → effect: large |W| → large λW² → non-zero gradient 2λW → GD subtracts that gradient → |W| becomes smaller.
same numerical · side-by-side

Ordinary GD vs GD + L2

Use the same starting point in both cases: W = 5, α = 0.1, λ = 0.5, and the teaching loss Ldata = (W − 3)².

ordinary gradient descent

No regularization

1 · data lossLdata = (5 − 3)² = 4
2 · data gradientgdata = 2(W − 3) = 2(5 − 3) = 4
3 · total gradientgtotal = gdata = 4
4 · gd updateWnew = 5 − 0.1(4) = 4.6
5 · after the stepNew data loss = (4.6 − 3)² = 2.56
Result: W goes from 5 → 4.6 using only gdata.
gradient descent + l2

Add the weight penalty

1 · data lossLdata = (5 − 3)² = 4
2 · add l2 penaltyλW² = 0.5(5²) = 12.5, so Ltotal = 4 + 12.5 = 16.5
3 · find both gradientsgdata = 4    and    gpenalty = 2λW = 2(0.5)(5) = 5
4 · total gradientgtotal = gdata + gpenalty = 4 + 5 = 9
5 · gd updateWnew = 5 − 0.1(9) = 4.1
6 · after the stepNew data loss = 1.21; new L2 penalty = 8.405; new total loss = 9.615
Result: W goes from 5 → 4.1. The extra reduction comes from gpenalty = 5.
Compare the same step: ordinary GD gives W = 4.6, while GD + L2 gives W = 4.1. The difference comes from the extra penalty gradient gpenalty = 2λW, not simply from making the loss number larger.
So the logic is not “higher loss automatically means smaller weight.” The logic is “weight-dependent penalty → extra gradient → GD update pushes |W| down.”

06
l1 regularization

Use absolute weight instead

✓ complete

L1 regularization adds the absolute value of the weight to the normal prediction loss. It cares about the size of the weight, not whether the weight is positive or negative.

for one weightLtotal = Ldata + λ|W|

|4| = 4 and |-4| = 4, so both have the same L1 penalty.

worked numericalOne weight

Ldata = 5
W = -4
λ = 0.1

1|W| = |-4| = 4
2λ|W| = 0.1 × 4 = 0.4
3Ltotal = 5 + 0.4 = 5.4

Student numerical 1

Ldata = 4 · W = 6 · λ = 0.05

Student numerical 2

Ldata = 3.5 · W = -7 · λ = 0.1

gradient descent with l1gtotal = gdata + λ sign(W)

For W > 0, sign(W) = +1, so L1 adds +λ to the gradient. For W < 0, sign(W) = −1, so L1 adds −λ. In both cases the GD update moves W toward zero.

worked numericalOrdinary GD vs GD + L1

W = 5
α = 0.1
gdata = 4
λ = 2

1Ordinary GD: Wnew = 5 − 0.1(4) = 4.6
2W is positive, so sign(W) = +1
3L1 gradient = λ sign(W) = 2(+1) = 2
4Total gradient = 4 + 2 = 6
5GD + L1: Wnew = 5 − 0.1(6) = 4.4
Compare: ordinary GD gives 4.6, while GD + L1 gives 4.4. The extra L1 gradient gives an additional push toward zero.
For L1, the extra push has almost constant size λ (away from W = 0). For L2, the extra push is 2λW, so it becomes stronger when |W| is large.

Add absolute values of all weights

✓ complete

With many weights, L1 adds all absolute weight values.

many weightsLtotal = Ldata + λ(|W₁| + |W₂| + |W₃| + ...)
worked example
W₁ = 2W₂ = -3W₃ = 1λ = 0.1Ldata = 5
|2| + |-3| + |1| = 6penalty = 0.1 × 6 = 0.6Ltotal = 5 + 0.6 = 5.6

why l1 is differentL1 is more likely to make some weights exactly zero.

08
dropout

Train many temporary pathways, not one fixed pathway

✓ complete

Dropout randomly switches off some hidden-neuron outputs during training. A switched-off neuron is not deleted; its output is temporarily treated as zero for that training pass. On the next pass, a different random set can be switched off.

dropout probabilityp = probability that a hidden neuron is switched OFF

If p = 0.5, each hidden neuron has a 50% chance of being off on a pass. It does not mean exactly half must be off every time.

01 · every epochA different subnetwork is used

The architecture is still the same, but a random subset of hidden outputs is temporarily zero.

02 · benefitNeurons cannot rely on the same partners

If one neuron is absent this time, other neurons must still learn useful representations. This reduces co-dependence.

03 · prediction timeThe full network is available

Standard dropout is turned off for normal evaluation or prediction, so the trained network uses all neurons.

Why this can help: dropout keeps changing the available pathway during training. That makes it harder for a particular group of neurons to memorize training-specific quirks together, so the learned representation can become more robust.
dropout

Keep the large network, temporarily hide neurons

Suppose a hidden layer contains 6 neurons and p = 0.5. We do not permanently turn it into a 3-neuron layer.

  • Epoch 1 may use one subset.
  • Epoch 2 may use a different subset.
  • Across training, all 6 neurons can still learn.
  • At prediction time, the full layer is available.
permanently smaller network

Actually remove layers or neurons

If we reduce a 6-neuron layer to 3 neurons, those missing neurons are gone in every epoch and at prediction time.

  • The same smaller architecture is always used.
  • Model capacity is permanently reduced.
  • This can also reduce overfitting, but it may underfit if we remove too much capacity.
  • It is therefore not the same mechanism as dropout.

batch normalization

Keep neuron activations on a stable scale

✓ complete

Batch normalization (BN) normalizes the values produced by a neuron or feature across a mini-batch. A mini-batch is simply a small group of training examples processed together. BN first recenters these values around 0 and rescales them to roughly unit variance, then learns its own scale γ and shift β.

main ideaz = (x − μB) / √(σ²B + ε)

μB is the mini-batch mean and σ²B is the mini-batch variance. The tiny ε only prevents division by zero.

learned scale and shifty = γz + β

Normalization does not force every layer to stay permanently at mean 0 and variance 1. The network can learn the useful scale and offset again through γ and β.

worked exampleNormalize one neuron's values across a mini-batch

Mini-batch values:
x = [0, 0, 2, 2]

For easy arithmetic, ignore ε here because the variance is not zero.

1Mean: μB = (0 + 0 + 2 + 2) / 4 = 1
2Variance: σ²B = [1 + 1 + 1 + 1] / 4 = 1
3Standard deviation = √1 = 1
4Normalize: z = (x − 1) / 1 = [−1, −1, 1, 1]
5If γ = 2 and β = 0.5, then y = 2z + 0.5 = [−1.5, −1.5, 2.5, 2.5]
Notice: BN changes the scale of activations. It does not add a penalty such as λW² or λ|W| to the loss.
01 · why normalize?Keep internal values from drifting to very different scales

When activations stay on a more stable scale, later layers receive values that are easier to work with.

02 · training benefitOptimization usually becomes easier and more stable

BN can make training less sensitive to initialization and often allows faster learning.

03 · regularization effectMini-batch statistics add a little noise during training

Different mini-batches have slightly different means and variances. That randomness can give a mild regularizing effect, although BN's main purpose is training stabilization.

Important distinction: L1/L2 act directly on weights. Dropout switches neuron outputs off. Batch normalization rescales activations. These methods can all influence generalization, but they work in different ways.

early stopping

Stop before the model starts memorizing

✓ complete

Early stopping watches validation performance while training continues. Training loss may keep improving, but if validation loss starts getting worse, the model may be beginning to overfit.

01Train normally

After each epoch, calculate training and validation loss.

02Watch validation loss

We want it to decrease because validation data represents unseen examples.

03Keep the best point

When validation performance stops improving, stop and keep the best model.

pocket reference

Seven ideas to keep

Regularization
A broad family of methods for reducing overfitting; not all of them shrink weights directly.
Large weights
Can make a model react strongly to small input changes and create sharp local decisions.
L2
Add λΣW². Its extra gradient is proportional to W, so large weights receive a stronger push.
L1
Add λΣ|W|. It is more likely than L2 to produce exact zero weights.
Dropout
Temporarily switches off random neuron outputs during training so learning is not tied to one exact pathway.
Batch normalization
Normalizes intermediate activations with mini-batch statistics, then learns a scale γ and shift β. Its batch noise can add a mild regularizing effect.
Early stopping
Stops training when validation performance stops improving, before continued fitting increases overfitting.
